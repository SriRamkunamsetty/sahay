## 4. How to Record & Attach the Local Demo Video for PR #20

To satisfy the mentor's video request for PR #20:
1. **Start the local app**:
   ```bash
   npm run dev
   ```
2. Open `http://localhost:3000` in Chrome/Edge.
3. Switch to the **Settings** view in the sidebar.
4. Open the Windows Game Bar (`Win + Alt + R` or `Win + G`) or any screen recorder (OBS / Loom / QuickTime).
5. Record a quick **10–15 second clip**:
   - Move the **Speech Rate** slider (e.g. from 0.95x to 0.80x for elder pacing).
   - Move the **Speech Pitch** slider.
   - Click **"Test Voice Sample"** to hear the audio playback.
   - Open the **Voice Assistant** floating button and ask a brief question.
6. Drag and drop the `.mp4` / `.webm` (or `.gif`) directly into the comment box on **[PR #20](https://github.com/archangel2006/sahay/pull/20)** and click "Comment".
